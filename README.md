# Central Rápida NFS-e 2026

PWA mobile-first criada como bônus operacional do **Kit Visual NFS-e Nacional 2026**.

## Recursos
- 20 guias rápidos baseados no conteúdo principal
- busca global
- atalhos para emissão, consulta, cancelamento, substituição e erros
- assistente de diagnóstico
- cadastro local de clientes e serviços
- controle mensal de NFS-e
- exportação CSV
- backup/restauração JSON
- checklists com persistência
- instalação como PWA
- funcionamento offline após o primeiro acesso
- dados armazenados apenas no navegador do usuário

## Segurança e privacidade
Não há backend nesta versão. Cadastros e controles ficam em `localStorage` no dispositivo. O app é material de apoio e não substitui legislação, contador ou orientação oficial.

## Branch
Esta versão está na branch `nfse-app` para não alterar o conteúdo atual da branch `main`.
